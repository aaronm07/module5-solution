Module 5 Coding Assignment

The Specials tile chooses a random category and sends the user to that category page.

Files:
- index.html
- css/styles.css
- js/script.js
- snippets/home-snippet.html

The home-snippet.html file is included as the assignment's original-style template.
The random category value is handled in JavaScript.

To test:
1. Open index.html.
2. Click Specials.
3. A random category should appear.
4. Go back Home.
5. Click Specials again and repeat several times.
